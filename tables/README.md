# tables/ -- result tables for the paper outline

Generated by `ops/make_tables.py` from committed `results/` artifacts only (never `scores.parquet`):
`sbatch ops/make_tables.sbatch` (all tables) and `sbatch ops/verify_tables.sbatch --determinism` (independent check).
Applicability of every metric to every test is decided by `rules.json` (explained in `RULES.md`) from the metric's
inputs, its definedness and the test design -- never from a verdict.

```
INDEX.csv         every table: id, path, section, paper part, slot, rows, generator hash, licence flag, status
audit/            A1 metric contracts - A2 test inventory - A3 metric x test applicability - A4 denominator restatement - A5 main metric set
main/             T1 design - T2 datasets - T3 (1A) - T4 (1B)  |  T5 (2A) - T6 (2B)      Part 1 : Part 2 = 38 : 32 rows
supp/             S01 ... S25 (see INDEX.csv)
spec/             hand-curated inputs: tests.csv (30 tests), metric_universe.txt (216 names), derived/ (small aggregates from the parquet)
```

## Main-text rule
Only metrics valid in BOTH Part 1 and Part 2 appear in T3-T6 (`audit/A5_main_metric_set.csv`, `role == main`: 29 structure-space
keys). Whole-protein and sequence-only metrics are supplement comparators; in Part 2 they appear only as a-priori reference rows.
Prediction-based metrics are provisional until experiments 1B and 2B hand back (rows marked `blocked_on_1B/2B`).
